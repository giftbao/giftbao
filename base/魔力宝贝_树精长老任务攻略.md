## 前置条件
- 无前置任务

- 推荐携带：200血瓶、少量料理、地水水晶（克制树精）

## 任务道具清单
| 道具 | 获取方式 | 用途 |
| ---- | ---- | ---- |
| 火把 | 维诺亚村医院 艾里克 | 进入树精洞窟 |

## 详细流程
1. 前往【维诺亚村医院(61,53)】，找到NPC 佣兵艾里克(7,5)，全队对话选【是】，每人获得【火把】
2. 出维诺亚村南门，前往芙蕾雅岛【(422,438)】，持有火把调查树洞，进入【树精洞窟】
    > 洞窟1~3层，随机遇敌：树精、翠绿菇
3. 一路清怪走到洞窟底层【树精长老之间】
4. 调查祭坛，触发BOSS战：树精长老 + 4只树精护卫
    - BOSS技能：强力风刃、单体补血、召唤小树精
    - 战术建议：优先清小怪，最后集火长老；传教保持血量
5. 战斗胜利，全队获得【长老之根】，地上拾取【生命之花】
6. 返回维诺亚村，找艾里克对话交付【生命之花】，完成任务

## BOSS战信息
- BOSS：树精长老
- 等级：Lv30
- 属性：风8地2
- 血量：约2200
- 掉落：长老之根、树精的叶子、少量魔币
- 逃跑：❌ BOSS不可逃跑

## 任务奖励
- 固定：魔币 1500G / 每人
- 可选二选一：
  1. 【树精的护符】：防御+3、精神+2，称号【森林守护者】
  2. 【生命种子】：宠物使用，体力+3
- 额外：弓箭手就职必备凭证（如需就职弓箭手保留长老之根）

## 重点注意事项 ⚠️
1. 火把丢了需要回艾里克重新领取
2. 任务中途登出、掉线，道具会保留，可以继续跑
3. 树精洞窟迷宫随机，跟着地图标记走，容易迷路
4. 若队伍有人已经完成本周任务，无法再次拿奖励，但可以帮忙战斗
5. 私服改动提示：部分私服BOSS血量、奖励有调整，以服内设定为准
